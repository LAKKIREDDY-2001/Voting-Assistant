# CivicPulse India 🗳️

CivicPulse India is an interactive, AI-powered election assistant designed to help Indian citizens navigate the democratic process with clarity. Built with a focus on the guidelines set by the Election Commission of India (ECI), it provides a comprehensive roadmap for voter participation in Lok Sabha and Vidhan Sabha elections.

## 🌟 Key Features

- **AI-Powered Civic Assistant**: A Gemini-based chat interface grounded in Election Commission of India (ECI) data to answer questions about voter registration (Form 6), EPIC cards, and polling procedures.
- **Interactive Lifecycle Timeline**: A visual, step-by-step roadmap of the Indian election cycle—from Voter ID registration to result declaration.
- **Voter Toolkit**: Curated modules covering eligibility requirements, EVM/VVPAT verification, and alternative ID documents.
- **Direct ECI Resource Access**: Quick-links to official portals like NVSP, Electoral Search, and the ECI website.

## 🛠️ Approach & Logic

### 1. Indian Election Grounding
The AI Assistant is specifically tuned for the Indian context using **Gemini 3 Flash** with **Google Search Grounding**. It understands terms like "Booth Level Officer (BLO)", "Model Code of Conduct", and "Constituency Search".

### 2. Regulatory Compliance
- **Non-Partisan Design**: The assistant is strictly neutral, providing only procedural and factual information as recommended for election assistants.
- **Grounding in Official Sources**: Every response encourages verification via `voters.eci.gov.in`.

### 3. Professional Architecture
- **Tailwind CSS v4** & **Framer Motion**: Delivers a polished, "Professional Polish" dashboard aesthetic.
- **React 19**: Ensures high performance and accessibility.
- **Zero-Retention Privacy**: No user data or voter IDs are stored, ensuring complete privacy.

## 🗳️ Chosen Vertical
**Election Assistant (India)**: Tailored for first-time voters, urban citizens, and those needing help with the digital transformation of Indian elections (NVSP, Voter Helpline).

## 🚀 How It Works
1. **Lifecycle Map**: Browse the 5 major phases of the Indian election process.
2. **AI Assistance**: Ask questions like "How do I update my address in my Voter ID?" or "What is a VVPAT slip?"
3. **Registration Links**: Guided buttons take users directly to the NVSP Form 6 portal.

## 📌 Assumptions
- The assistant follows the general federal/state election cycle structure of India.
- Users are encouraged to cross-verify specific booth-level details with their local BLO or the Voter Helpline App.
